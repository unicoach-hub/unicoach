2. Technology Decision Framework

1. Node.js + Express vs NestJSRuntime
What is it?
A JavaScript/Node.js HTTP server using the Express.js minimalist framework to handle REST API requests.
How does it work & Problem solved?
Express's non-blocking event loop handles thousands of concurrent API requests on a single thread. The 7-layer middleware pipeline processes each request through security, authentication, validation, and logging before hitting business logic.
What alternatives existed?
NestJS: Opinionated TypeScript framework with DI containers — excellent for large enterprise teams but adds significant boilerplate overhead for a 2–3 person startup. Fastify: 2x faster than Express, but smaller ecosystem.
Why did we choose this approach?
Maximum velocity for a startup: Express's minimal structure lets us ship features faster, and the full Node.js ecosystem (Mongoose, Groq SDK, Twilio) provides first-class integration support.
2. Zod Schema Validation vs Manual ValidationData Safety
What is it?
TypeScript-first runtime schema validation library that rejects malformed API requests before they reach business logic.
How does it work & Problem solved?
Without Zod, invalid data (e.g., non-numeric phone numbers, missing email fields) silently propagates into MongoDB, creating corrupt lead documents. Zod rejects invalid payloads at the middleware layer with structured 400 error responses.
What alternatives existed?
Joi: Runtime-only, no TypeScript integration. Manual if-else validation: Repetitive, inconsistent, and error-prone.
Why did we choose this approach?
Single source of truth for API contracts: schema definitions simultaneously validate runtime data and infer TypeScript types.
💡 Senior Interview Defense: "Walk me through your backend architecture"

"UniCoach's backend is a Node.js 22 micro-monolith with 32 REST endpoints organized as a clean MVC: routes declare HTTP verbs and paths, controllers hold business logic, and Mongoose models handle persistence. Every inbound request traverses a 7-layer middleware pipeline — CORS, rate limiting, JWT auth, NoSQL injection sanitization, Zod schema validation, access logging, and a global error handler. This pipeline catches security issues, auth failures, and malformed payloads before they ever reach business logic."
