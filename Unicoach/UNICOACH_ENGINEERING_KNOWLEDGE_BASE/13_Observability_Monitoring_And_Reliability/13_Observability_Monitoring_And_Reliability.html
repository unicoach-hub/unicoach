2. Technology Decision Framework

1. Sentry APM vs Raw Cloud Logs vs DatadogObservability
What is it?
Sentry intercepts every unhandled Node.js exception and React component error, grouping them with full stack traces, user breadcrumbs, and environment context.
How does it work & Problem solved?
Without APM, a student who encounters a 500 error sees a generic failure message and you only discover the bug if they contact support. Sentry captures the error 100ms after it occurs, pushes an alert, and shows the exact line of code and preceding user actions that caused it.
What alternatives existed?
Raw Render/CloudWatch Logs: Errors buried in thousands of lines, no grouping, no alert thresholds. Datadog: Enterprise pricing ($150–$500/month) with complex agent installation.
Why did we choose this approach?
Free tier covers 5,000 errors/month — sufficient for early-stage. Zero-config Node.js SDK integration. Source map uploads de-minify production stack traces to exact original source lines.
2. Sanitized Health Endpoint vs Verbose Debug ProbeSecurity
What is it?
A GET /api/health endpoint that returns only {"status":"UP","timestamp":...} in production, withholding process memory stats and runtime version details.
How does it work & Problem solved?
Many tutorials expose process.memoryUsage() and process.version in health endpoints. Attackers use automated scanners to discover Node.js version numbers and target known CVEs for that specific runtime version. Our sanitized response provides liveness confirmation while revealing zero infrastructure metadata.
What alternatives existed?
Verbose /health endpoints exposing Node version, heap usage, uptime — providing attackers a fingerprinting vector for targeted CVE exploitation.
Why did we choose this approach?
Satisfies PaaS liveness probe requirements while adhering to OWASP information hiding principles.
💡 Senior Interview Defense: "How do you ensure system reliability and observability?"

"UniCoach has a 4-pillar reliability stack. Sentry captures and alerts on every unhandled exception with breadcrumbs showing the exact user action sequence that triggered it. A lightweight access logger records every route's HTTP status and execution latency in milliseconds for trend analysis. The /api/health endpoint is deliberately sanitized — it returns only status:UP with no runtime metadata, preventing Node.js version fingerprinting by attackers. Finally, SIGTERM handlers drain in-flight requests before closing MongoDB connection pools — preventing any data corruption during rolling cloud deployments. Our RPO is under 1 hour via Atlas oplog snapshots and RTO under 15 minutes via instant Vercel rollbacks."
