STEP 1: GOOGLE SEARCH CONSOLE (GSC) INTEGRATION

Google Search Console is the most critical tool for your organic search growth.

1. Go to Google Search Console (https://search.google.com/search-console).
2. Enter your domain: https://unicoach.com (or your live production URL).
3. Verify ownership using the DNS TXT Record Method (recommended):
   * Copy the TXT value provided by Google (e.g., google-site-verification=xxxxxx).
   * Log into your Domain registrar (e.g., GoDaddy, Namecheap, Cloudflare).
   * Go to DNS Management -> Add New Record -> Choose TXT -> Set Name/Host to @ -> Paste the TXT value -> Save.
   * Go back to GSC and click Verify.

* TIP: If DNS verification is taking time, you can temporarily verify using the HTML File Upload method by placing the verification file in the public/ directory and rebuilding.

4. Once verified, go to the Sitemaps section in the left panel.
5. In the "Add a new sitemap" input, type: sitemap.xml and click Submit.

---

STEP 2: GOOGLE ANALYTICS 4 (GA4) INTEGRATION

GA4 lets you analyze which landing pages attract the most traffic.

1. Go to Google Analytics (https://analytics.google.com/).
2. Create an Account and Property for UniCoach.
3. Create a Web Data Stream and enter your URL.
4. Copy your Measurement ID (e.g., G-1234567890).
5. Open your live index.html file and paste the script inside the <head> tags:

<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-1234567890"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-1234567890');
</script>

PART 4: TECHNICAL & SCHEMA SEO ENHANCEMENTS
--------------------------------------------------------------------------------

Adding Schema Markups allows Google to display "Rich Snippets" (such as rating stars, FAQ dropdowns, or search boxes directly in the search results).

Example JSON-LD Schema (To paste in index.html or dynamic router)
For your GPA calculator, you can inject this JSON-LD schema into the page structure to get rich search styling:

{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "UniCoach CGPA to GPA Calculator",
  "operatingSystem": "All",
  "applicationCategory": "EducationalApplication",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "INR"
  },
  "description": "Convert Indian CGPA/percentage to U.S. 4.0 GPA scale instantly for admissions."
}
