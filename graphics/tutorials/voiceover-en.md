## Making the clips on the HeyGen website

The HeyGen API refused these clips for lack of API credits, but the account's plan credits work on the website. So please make them there:

- Make 4 videos, one per section above: `course-finder`, `scholarships`, `student-dashboard`, `mentor-dashboard`.
- In each video, add one scene per row, in the same order. In each scene the avatar says the "Nitya says" line exactly.
- Use the avatar named "Sakshi Mehta" with its default voice ("vo").
- Keep her usual background; no green screen needed. Portrait or landscape both work. Export as 1080p MP4.
- Name each file after its section, for example `course-finder.mp4`, and share all 4 in one Drive folder.

Each scene is cut out and placed on its step automatically, so no editing is needed on your side.
