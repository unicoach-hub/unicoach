# UniCoach tutorial videos: ready for voice-over

Four screen-recorded tutorials of the live UniCoach site, made for adding Nitya's voice (HeyGen) on top.

| File | What it shows |
|---|---|
| `course-finder.mp4` + `.srt` | Search a course, filter, shortlist, sign in to download |
| `scholarships.mp4` + `.srt` | Find scholarships you qualify for |
| `student-dashboard.mp4` + `.srt` | A new student's first steps: profile, roadmap, tools |
| `mentor-dashboard.mp4` + `.srt` | Mentor studio: setup, services, calendar, bookings, earnings, sharing |

## The videos

- 1920x1080, 30 fps, no sound.
- Each step is held on screen for as long as its voice line takes (paced at about 150 words a minute), so the voice fits without speeding anything up.
- No captions are burned in. The cursor, clicks and orange highlight rings show what is happening.
- The first and last few seconds are plain title cards (intro and outro), with room for a bigger Nitya.
- The student and mentor dashboards use made-up demo accounts (Aarav Sharma, Ananya Rao), so no real student's or mentor's data appears.

## The .srt files

Each `.srt` has the exact voice line for every step, with the time it should start and end. Import it into your editor (Premiere, CapCut, DaVinci) as a subtitle track and you can see where every line goes. The same lines are in `voiceover-en.md`.

## Adding Nitya

1. In HeyGen, make one clip per line, with the avatar named "Sakshi Mehta" and its default voice ("vo"). Or make one video per tutorial with one scene per line.
2. Place each clip at its start time from the `.srt`. If a clip runs longer than its slot, freeze the screen recording until the line ends.
3. Put Nitya in a corner as a round bubble. Bottom-left works best; keep the top 90 px clear (the site menu is there).
4. Please burn in the subtitles too (from the `.srt`), so the videos still make sense when they are played without sound.
5. Export MP4 (H.264 + AAC), 1920x1080 or 1280x720, ideally under 10 MB each.

Send the four finished videos back with the same file names, and they go straight onto the site.
